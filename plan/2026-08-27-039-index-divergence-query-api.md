# 功能6“指数背离”第四步：曲线与信号查询接口

## 目标

补齐试用期文档要求的查询接口，一次返回最新交易日的上证指数分钟曲线、昨收横线和MACD顶背离/底背离信号。

## 接口

```text
GET /api/indexDivergence/latest
```

接口无请求参数，返回：

- `tradeDate`：数据所属交易日。
- `previousClosePrice`：上证指数昨收价格，供前端绘制横线。
- `curveData`：按行情时间升序排列的分钟和当前价格。
- `signalData`：按确认时间升序排列的顶背离、底背离信号及两个比较区间的价格、MACD、DIF极值。

项目统一使用 `yyyy-MM-dd HH:mm:ss` JSON日期格式。

## 日期口径

- 上海时区交易日09:31后返回当天已经入库的数据。
- 交易日09:31前或非交易日返回上一交易日数据。
- 当日暂无数据时返回空曲线、空信号和空昨收，不伪造数值。

## 实现结果

- 新增 `IndexDivergenceQueryService`，负责最新交易日选择和查询结果组装。
- 分钟行情继续复用按时间范围升序查询。
