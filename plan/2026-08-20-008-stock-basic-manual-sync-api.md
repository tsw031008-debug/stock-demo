# 新增股票基础信息手动同步接口

日期：2026-08-20  
状态：已完成

## 完成内容

- 新增 `POST /api/stockBasic/synchronize`，用于受控手动触发当天股票基础信息同步。
- 接口按 `Asia/Shanghai` 获取当天日期，不允许传入历史日期，避免把当前清单错误标记为历史快照。
- 将交易日判断和采集编排封装到 `StockBasicSyncService`，手动接口和定时任务复用同一入口。
- 保留同日幂等保护；当天已经成功同步时返回保存数量0，不再次请求新浪。
- 非交易日返回保存数量0，不访问新浪。
- 同步异常继续由统一异常处理返回操作错误，不写入不完整数据。

## 接口响应示例

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "tradeDate": "2026-08-20",
    "savedCount": 5200
  }
}
```
