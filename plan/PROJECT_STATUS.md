## 当前接口

### 初始化交易日历

```text
POST /api/tradeCalendar/initialize
```

请求体：

```json
{
  "startDate": "2017-01-01",
  "endDate": "2026-12-31"
}
```

成功响应中的 `code` 为 `200`，操作错误为 `1000`，系统错误为 `500`。

### 判断是否为交易日

```text
GET /api/tradeCalendar/tradingDay?date=2023-06-26
```

返回查询日期以及 `tradingDay` 判断结果。

### 查询前第 N 个交易日

```text
GET /api/tradeCalendar/previousTradingDay?date=2023-06-26&offset=2
```

### 查询后第 N 个交易日

```text
GET /api/tradeCalendar/nextTradingDay?date=2023-06-26&offset=2
```

### 手动同步股票基础信息

```text
POST /api/stockBasic/synchronize
```

接口使用上海时区当天日期。非交易日或当天已经同步时，`savedCount` 返回0且不会请求新浪。

### 手动同步股票日行情

```text
POST /api/stockDailyQuote/synchronize
```

接口使用上海时区当天日期。非交易日或当天已经完整同步时，`savedCount` 返回0且不会请求腾讯。

### 手动同步股票资金流向

```text
POST /api/stockFundFlow/synchronize
```

接口使用上海时区当天日期。非交易日或当天沪深A股资金流向已经完整同步时，`savedCount` 返回0且不会请求东方财富。

### 按日期查询股票资金流向

```text
GET /api/stockFundFlow?tradeDate=2026-08-25&pageNum=1&pageSize=20
```

查询已入库的指定交易日资金流向，金额单位为元。结果按主力净流入金额从高到低分页返回；默认每页20条，最大100条。查询过程不会请求外部数据源。

### 查询最新市场水位

```text
GET /api/marketLevel/latest
```

当前成交额读取腾讯上证指数和深证综指实时成交额；历史均值聚合日线表中代码以0、3、6开头的沪深A股。返回市场风格、前3个交易日成交额均值、当前成交额和量比，成交额单位为亿元。

### 查询两市周月平均水位同比环比

```text
GET /api/marketLevel/periodComparison
```

返回最新完整交易日对应的周、月同比、环比和当前日均成交额。周同比为向前5个自然周，周环比为上一个实际交易周；月同比为去年同月，月环比为上月，金额单位为亿元。

### 查询涨速预警

```text
GET /api/stockAlert/speed?pageNum=1&pageSize=20
```

返回三日斜率严格大于两日斜率的股票，包含股票代码、名称、当前价格和当前涨幅。

### 查询开板提醒

```text
GET /api/stockAlert/openBoard?pageNum=1&pageSize=20
```

按文档卖一量、成交额、当前价及非ST条件返回候选股票，包含股票代码、名称、当前价格、当前涨幅和亿元成交额。

### 同步板块和成分股

```text
POST /api/plate/synchronize
```

交易日手动同步文档指定的同花顺三级概念板块及成分关系。

### 同步当天板块日线

```text
POST /api/plate/synchronizeDailyQuote
```

确认当天股票日行情完整后，计算并幂等保存当天板块日线。

### 查询当天板块涨停统计

```text
GET /api/plate/limitUpStatistics?pageNum=1&pageSize=20
```

交易日09:30后可查询，午休和收盘后允许查询最近行情。默认每页20条、最大100条，涨幅和涨停占比保留2位小数。
