# 功能13 科技股成交额异动

## 已确认口径与来源

- 需求文档：同花顺科技成分股排除名称包含ST的股票；三类独立筛选，再按涨幅绝对值取前5，最后按成交额降序展示。
- 用户确认：接口传入tradeDate作为T；即使查历史日期，也使用当前plateId=676成分股。
- 用户确认：连续3日指三次比较，需要T、T-1、T-2、T-3四个交易日；使用T日当日涨幅，允许三类重合。
- 需求阈值：公共条件为T日涨幅>0、成交额>1亿元；递增为三次相邻日成交额比>1.05；机构票为T成交额>5亿元且T/T-1>1.05；异动为T/T-1>2。全部严格大于，不新增“昨日≤5亿元”。
- 沿用已有技术：交易日历、成交额元单位、当前科技股数据源、按代码和日期查询原始行情的Mapper以及单股票排名DTO/VO。
- 已随方案确认的实现处理：无效日期拒绝；T日无记录报未就绪且不回退；分母非正或必要字段缺失不参与依赖该字段的分类；同分代码升序用于稳定前五选取及最终排序。

## 最小实现

- 新增查询DTO、三组榜单DTO/VO、Service及独立计算组件，接口放入已有StockAlertController。
- 复用selectTechnologyStockQuotes，仅将XML中“六个日期”的注释改为“目标日期”；无新SQL、表、迁移、定时任务、缓存、依赖。
- 成交额比例用乘法比较，不引入除法精度；本功能不依赖收盘价，因此没有复制功能12的正收盘价校验。
- countByTradeDate仅判断零记录，不设数量门槛，不认定非零即完整。此前已核查上游允许PARTIAL，当前方案不新增整日完整性认证。
- 三个榜单各最多5条，是固定Top N结果，不新增无业务意义的分页参数。

## 接口

`GET /api/stockAlert/technologyStockTurnover?tradeDate=2026-09-08`

参数tradeDate必填，格式yyyy-MM-dd。未来日期、非交易日拒绝；当日未落库返回业务错误。接口错误沿用现有Result封装。

成功响应data：

```json
{
  "statisticsDate": "2026-09-08",
  "increasingStocks": [],
  "institutionalStocks": [],
  "abnormalStocks": []
}
```

三个字段分别为成交额递增、机构票监测、成交额异动。每条股票返回rank、stockCode、stockName，rank为最终成交额展示顺序。空数组表示本次数据下没有符合条件的股票，不表示数据完整性已认证。
