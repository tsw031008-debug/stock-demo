# 功能10指数ETF日行情表

## 目标

为上证50、沪深300、创业板50和中证1000对应ETF的5日涨幅计算提供独立日行情存储，不将ETF混入沪深京A股表。

## 表结构

- 新增V16迁移，创建 `index_etf_daily_quote`。
- 保存ETF代码、对应指数展示名称、交易日、行情时间、收盘价、数据来源和采集时间。
- 使用 `(etf_code, trade_date)` 唯一约束，防止同一ETF同一交易日重复数据。
- 使用 `(trade_date, etf_code)` 查询索引，支持按交易日批量读取4只ETF。

## 验证

- H2集成测试验证建表成功、正常写入成功且重复ETF交易日写入被拒绝。
- 本地MySQL `stock_demo` 已执行V16，字段、主键、唯一约束和日期查询索引均已核对。
