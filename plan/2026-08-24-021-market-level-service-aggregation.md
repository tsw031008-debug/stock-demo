# 市场水位历史成交额改由Service汇总

## 目标

收窄市场水位相关 SQL 的职责，使 Mapper 只查询业务计算需要的原始字段，成交额汇总和数据完整性统计统一在 Service 中完成。

## 实现

- 将 Mapper 方法调整为按指定的5个历史交易日查询沪深A股成交额原始记录。
- SQL 只返回 `trade_date` 和 `turnover_amount_yuan`，保留沪深A股代码范围过滤和日期排序。
- 删除 SQL 中的 `SUM`、`COUNT`、`GROUP BY` 和 `LIMIT`。
- 新增 `MarketTurnoverRecordDto` 承接成交额原始记录，避免使用日汇总 DTO 表达单条数据。
- Service 通过交易日历确定统计日前5个交易日，不包含当前统计日。
- Service 按交易日完成成交额求和、总记录数统计和非空成交额记录数统计，再交给市场水位计算组件完成风格与量比计算。

## 业务口径

- 历史范围仍为当前统计日前5个交易日。
- 历史成交额仍只统计代码以0、3、6开头的沪深A股。
- 任一原始记录的成交额为空时，Service 保留完整性差异，由计算组件拒绝使用不完整数据。
- 市场风格、金额单位、阈值和小数位规则均未改变。
