# 功能9指数大小风格实现

## 目标

按试用期文档固定展示上证50、上证指数、创业板综指和中证1000最近5个完整交易日的涨幅，并标记每日最强和最弱指数。

## 数据来源

- 日常盘后数据：腾讯批量行情接口，一次请求 `sh000016,sh000001,sz399102,sh000852`。
- 历史回补：离线 Python 脚本通过 AKShare `stock_zh_index_daily` 获取新浪指数日线。
- 应用查询：只读取本地 `index_daily_quote`，不在 Web 请求中临时调用第三方数据源。
- Java 核心服务不依赖 Python 进程，Python 只用于一次性或指定区间回补。

## 实现内容

- 新增 V15 迁移，以 `(指数代码, 交易日)` 唯一保存收盘价、前收盘价、行情时间和数据源。
- 新增15:06盘后同步任务和15:06后启动补采；非交易日或当日数据已完整时不重复请求。
- 腾讯响应必须包含四个指数，且行情日期必须与目标交易日一致，否则不写入残缺数据。
- 历史脚本从本地交易日历取目标日期，使用新浪完整历史序列计算回补起始日的前收盘价，并幂等 upsert。
- 历史脚本不读取系统代理；真实回补时东方财富 `push2his` 持续中断连接，四个指数均已验证可从新浪指数日线获取。
- 涨幅口径为 `(当日收盘价 ÷ 前收盘价 - 1) × 100%`，保留2位小数。
- 每个交易日选涨幅最大者为 `STRONG`、最小者为 `WEAK`；四者全部相等时均为 `NONE`，部分并列时按固定展示顺序取第一个。
- 新增查询接口 `GET /api/indexStyle/latest`，返回最新完整交易日及最近5个交易日的四指数结果。
