# 股票资金流向按日期查询

## 状态

已完成。

## 实现范围

- 新增 `GET /api/stockFundFlow` 查询接口，接收交易日期、页码和每页数量。
- 查询日期必须是交易日；非交易日直接返回参数错误，不访问资金流向数据表。
- 默认每页20条，最大每页100条。
- 按主力净流入金额从高到低排序，金额相同时按股票代码升序，保证分页结果稳定。
- 接口只查询已入库的数据，不在查询过程中调用东方财富或启动历史回补。
- 无数据日期和超出总数的页码返回空列表，并保留正确的总记录数。

## 数据口径

- 金额单位为元。
- 返回交易日期、股票代码、股票名称、最新价、涨跌幅，以及主力、超大单和大单净流入金额及占比。
- SQL 只负责按日期筛选、排序和分页，不进行业务汇总或指标计算。

## 验证结果

- Controller 测试覆盖默认分页参数、日期格式和响应字段。
- Service 测试覆盖正常分页、非交易日、无数据和超出总数的分页边界。
- Mapper 集成测试覆盖日期筛选、排序和分页。
- 执行 `./mvnw.cmd test`，111个测试全部通过，失败0、错误0。
