# 市场水位真实接口验证

## 验证目标

使用已启动的本地应用真实调用市场水位接口，验证 Controller、交易日历、历史行情、Service 汇总、腾讯实时行情和计算组件的完整链路。

## 请求

```text
GET /api/marketLevel/latest
```

```json
{
  "code": 200,
  "data": {
    "currentTurnoverYi": 20074.56,
```

## 核对结果

- 统一响应体业务码为200，接口调用成功。

- 当前成交额、前3个交易日成交额均值和量比均保留2位小数。
- 前3个交易日成交额均值为21559.74亿元，大于10000亿元，返回“偏机构风格”符合阈值口径。
- 量比0.89表示当前成交额约为前5个交易日平均成交额的89%，结果口径正常。

市场水位真实查询链路验证通过。腾讯实时成交额能够正常解析，本地历史行情能够完成前5个交易日查询和Service汇总，接口响应结构与计算结果符合已确认需求。
