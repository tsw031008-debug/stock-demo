# 市场水位查询实现

## 目标

按已确认业务口径实现最新市场水位查询接口：

- “市场流水”按需求原文解释为“市场水位”。
- 市场风格阈值为 `<8000`、`8000~10000`（包含边界）、`>10000`。
- 中间区间名称为“过渡期”。
- 量比使用当前成交额除以前 5 个交易日成交额均值，前 5 日不包含当前统计日。
- 成交额和量比统一保留 2 位小数。
- 响应不增加统计日期字段。

## 实现内容

### 查询接口

新增接口：

```text
GET /api/marketLevel/latest
```

响应包含：

- `style`：市场风格。
- `previousThreeDayAverageTurnoverYi`：前 3 个交易日成交额均值，单位亿元。
- `currentTurnoverYi`：当前最新两市成交额，单位亿元。
- `volumeRatio`：当前成交额与前 5 个交易日成交额均值的比值。

Controller 只负责响应对象转换和统一结果封装，字段已补充 OpenAPI 描述和单位说明。

### 当前成交额

新增腾讯市场水位数据源适配器，请求：

```text
http://qt.gtimg.cn/q=s_sh000001,s_sz399106
```

- 使用 GB18030 解码。
- 分别解析上证指数和深证综指成交额字段。
- 将两个指数的万元成交额合计并统一转换为元后传入计算组件。
- 校验空响应、指数缺失、字段不足、非数字、负数、重复指数和格式变化。
- 设置连接超时、读取超时、请求间隔和最多 2 次有限请求尝试。

### 历史成交额

扩展 `StockDailyQuoteMapper` 及其 XML：

- 查询统计日之前最近 5 个有日线数据的交易日。
- 只聚合代码以 `0`、`3`、`6` 开头的沪深 A 股。
- 排除北交所股票。
- 同时返回总记录数和非空成交额记录数，避免 SQL `SUM` 静默忽略 NULL 后继续计算。
- 按交易日倒序返回，使前 3 条对应最近 3 个交易日。

本功能直接复用现有日线表，不新增表和 Flyway 迁移。

### 计算与日期

新增独立 `MarketLevelCalculator`：

- 使用 `BigDecimal` 完成全部金额、均值、阈值和量比计算。
- 风格判断使用未舍入的前 3 日成交额总和比较，避免临界值提前舍入。
- 最终响应统一保留 2 位小数并使用 `HALF_UP`。
- 历史不足 5 日、记录数不完整、日期未倒序、负数或前 5 日均值为 0 时拒绝计算。

Service 使用 `Asia/Shanghai`：

- 交易日 09:30 及以后，以当天为统计日。
- 交易日 09:30 之前，以前一交易日为统计日。
- 非交易日，以最近一个交易日为统计日。
- 历史 SQL 始终使用严格小于统计日的日期，因此前 5 日不包含当前统计日。

## 配置

新增以下可通过环境变量覆盖的配置：

- `MARKET_LEVEL_SOURCE_URL`
- `MARKET_LEVEL_SOURCE_CONNECT_TIMEOUT`
- `MARKET_LEVEL_SOURCE_READ_TIMEOUT`
- `MARKET_LEVEL_SOURCE_REQUEST_INTERVAL`

未新增依赖。

## 测试

新增 21 个市场水位相关测试，覆盖：

- 前 3 日均值、前 5 日量比和 2 位小数。
- 8000、10000 两个边界及三类市场风格。
- 历史不足、NULL 成交额、除零和日期顺序校验。
- 腾讯正常响应、顺序变化、空响应、指数缺失、字段缺失、非数字、负数和乱码。
- 沪深股票聚合与北交所排除。
- 交易日盘中、开盘前、周末、节假日和跨年统计日选择。
- Controller 返回字段及不包含 `statisticsTradeDate`。
