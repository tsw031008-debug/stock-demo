# 市场水位业务分析

## 目标

根据试用期功能需求文档，实现一个无入参的最新市场水位查询接口，向前端返回市场风格、前 3 个交易日成交额均值、当前最新两市成交额和量比。

本阶段只完成业务分析，不实现代码。

## 原始需求口径

需求文档中的功能名称是“市场水位”，不是“市场流水”。该功能用于衡量沪深两市成交活跃度，不是查询逐笔成交、资金流水或个股资金流向。

接口核心返回字段：

1. 市场风格：按当前统计日之前 3 个交易日的两市成交额均值判断。
2. 前 3 个交易日成交额均值。
3. 当前最新两市成交额。
4. 量比：当前最新两市成交额除以过去 5 个交易日的成交额均值。

所有返回给前端的成交额统一使用“亿元”。

## 数据来源

### 当前最新两市成交额

调用腾讯简版指数行情：

```text
http://qt.gtimg.cn/q=s_sh000001,s_sz399106
```

- `s_sh000001`：上证指数。
- `s_sz399106`：深证综指。
- 响应按 `~` 分隔后，人类计数的第 8 个字段，即数组下标 7，为成交额，单位“万元”。
- 两个指数的成交额相加后除以 10000，转换为“亿元”。
- 文档示例中两个值为 `29234524` 万元和 `2445973` 万元，合计 `31680497` 万元，即 `3168.0497` 亿元。

腾讯响应必须显式使用 GB18030 解码，并校验两个指数均存在、字段数量足够、成交额非空且非负。任一指数缺失或格式变化时整体失败，不使用 0 冒充真实数据。

### 历史两市成交额

直接聚合现有 `stock_daily_quote.turnover_amount_yuan`：

- 按 `trade_date` 分组。
- 只统计股票代码以 `0`、`3`、`6` 开头的沪深 A 股。
- 排除以 `4`、`8`、`9` 开头的北交所股票。
- 停牌股票的合法 0 成交额参与求和。
- NULL 成交额不能被静默忽略；每个交易日应同时返回总记录数和非空成交额记录数，由 Service 校验一致。
- 历史回补数据虽然因盘口字段缺失标记为 `PARTIAL`，但成交额完整，不能仅筛选 `COMPLETE`。

当前数据库已有近两年日线数据，覆盖前 5 个交易日计算所需历史范围，无需新增历史采集任务。

## 计算口径

设统计日为 `T`，`A(T)` 为当前最新两市成交额，单位亿元。

```text
前3日均值 = (A(T-1) + A(T-2) + A(T-3)) / 3
前5日均值 = (A(T-1) + ... + A(T-5)) / 5
量比 = A(T) / 前5日均值
```

其中 `T-N` 均指交易日，不是自然日。前 3 日和过去 5 日均不包含当前统计日，避免量比把当前值同时放入分子和分母。

计算过程使用 `BigDecimal`。建议先用未舍入值完成风格和量比计算，最后仅在响应层统一展示精度，避免临界值因提前舍入产生误判。

## 统计日规则

接口语义是“最新市场水位”，后端内部按以下规则确定统计日：

- 交易日 09:30 及以后：统计日为当天，当前成交额为腾讯实时累计值。
- 交易日 09:30 之前：统计日为前一交易日。
- 非交易日：统计日为最近一个交易日。

该规则能避免周末或开盘前把腾讯返回的上一交易日成交额误当成新交易日数据。所有时间判断使用 `Asia/Shanghai`。现有日线表已通过 `trade_date` 标识交易日，非交易日不会同步新记录，因此响应中不额外返回统计日期字段。

## 市场风格

风格只根据前 3 个交易日成交额均值判断，不使用当前实时成交额。

文档已明确：

- 8000 亿元以下：`偏游资风格`。
- 10000 亿元以上：`偏机构风格`。

用户已确认阈值范围：

- 小于 8000 亿元：`偏游资风格`。
- 8000 至 10000 亿元：包含 8000 和 10000 两个边界，风格名称为 `过渡期`。
- 大于 10000 亿元：`偏机构风格`。

## 接口建议

```text
GET /api/marketLevel/latest
```

建议响应数据：

```json
{
  "style": "偏游资风格",
  "previousThreeDayAverageTurnoverYi": 7654.32,
  "currentTurnoverYi": 8123.45,
  "volumeRatio": 1.06
}
```

响应只返回文档明确要求的四个核心字段，不增加统计日期元数据。成交额和量比统一保留 2 位小数。

## 最小实现边界

不新增市场水位表，不新增定时任务，不引入 Redis 缓存。实现范围仅包括：

1. 腾讯市场成交额数据源适配器，负责请求、限频、有限重试、GB18030 解码和字段校验。
2. 日线 Mapper XML 历史成交额聚合查询。
3. 独立可单测的市场水位计算组件。
4. Service 业务编排和交易日选择。
5. Controller、响应 VO、配置项和 OpenAPI 注解。

若后续出现高频访问、外部接口压力或多实例一致性要求，再单独评估短时缓存；当前不提前增加该复杂度。

## 异常与边界

- 腾讯任一指数缺失、响应为空、成交额非法：接口失败，不返回部分数据。
- 找不到前 5 个完整交易日：接口失败，并明确提示历史数据不足。
- 历史某日存在 NULL 成交额：接口失败，不用其余股票求和冒充完整市场数据。
- 前 5 日均值为 0：拒绝计算量比，避免除零。
- 周末、节假日、跨月和跨年：必须通过交易日历选取日期。
- 当前实时数据与历史聚合采用不同来源，可能存在小幅口径差异；这是需求文档明确给出的最小实现方式，响应文档应标注来源。

## 测试与验收标准

### 计算单元测试

- 正确计算前 3 日均值、前 5 日均值和量比。
- 覆盖低于 8000、中间区间、高于 10000，以及两个边界值。
- 覆盖除零和历史数量不足。
- 验证中间计算不因提前舍入改变风格。

### 数据源解析测试

- 正常解析两个指数并完成万元到亿元转换。
- 覆盖空响应、缺少一个指数、字段缺失、非数字、负数、响应顺序变化和乱码。
- 固定样本测试，不在自动测试中请求腾讯真实接口。

### Mapper 集成测试

- 按交易日正确汇总 `0`、`3`、`6` 开头股票。
- 排除 `4`、`8`、`9` 开头股票。
- 覆盖停牌 0 成交额、NULL 成交额检测、跨周和跨月交易日。

### Service 与接口测试

- 覆盖交易日盘中、开盘前、周末和节假日的统计日选择。
- 验证查询严格使用统计日前 5 个交易日且不含统计日。
- 验证返回字段、单位和异常响应。
- 最相关测试和 `./mvnw test` 全部通过。
