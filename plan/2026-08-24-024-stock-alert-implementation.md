# 功能3股票预警实现

## 目标

完成试用期需求文档功能3的涨速预警和开板提醒接口，并确保实时行情、历史价格、计算、分页和异常提示职责清晰。

## 已完成

- 新增涨速预警接口`GET /api/stockAlert/speed`。
- 新增开板提醒接口`GET /api/stockAlert/openBoard`。
- 两个接口支持`pageNum`和`pageSize`分页，默认每页20条，单页最大100条。
- 两个接口复用同一份60秒进程内全市场实时行情快照，同一时刻只允许一个线程刷新。
- 快照刷新前分批读取当天沪深京A股完整清单，少于3000只、清单读取不完整或腾讯行情数量不完整时终止查询。
- 非交易日返回“当前为非交易日”，交易日09:30前返回“当前不在交易时间”；后续已放开午休和收盘后查询。
- 涨速计算使用实时当前价、`T-1`和`T-2`历史收盘价，严格判断三日斜率大于两日斜率。
- 涨速结果按当前涨幅、斜率差和股票代码依次排序，对外只返回股票代码、名称、当前价格和当前涨幅。
- 开板提醒使用卖一量为0、成交额大于0、当前价大于0、名称非`ST`或`*ST`前缀条件。
- 开板结果按当前涨幅、成交额和股票代码依次排序，对外增加亿元成交额，不返回卖一量。
- 当前价格、当前涨幅和亿元成交额统一保留2位小数。
- Mapper XML只查询股票代码、交易日和收盘价原始字段，涨幅、斜率、筛选、排序和分页均在Service及独立计算组件完成。
- 新增Controller、Service、计算组件、DTO、VO和Mapper测试。

## 接口示例

```text
GET /api/stockAlert/speed?pageNum=1&pageSize=20
GET /api/stockAlert/openBoard?pageNum=1&pageSize=20
```

分页数据结构：

```json
{
  "pageNum": 1,
  "pageSize": 20,
  "total": 1,
  "records": []
}
```
